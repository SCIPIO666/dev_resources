# DevResource Hub

A curated collection of 340+ developer resources — courses, tools, APIs, projects, and career resources.

## Features

- 🔍 Instant search across all resources
- 🏷️ Level filters (Free / Paid / Beginner / Intermediate / Advanced)
- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Zero dependencies (no frameworks, no build step)
- 🎨 Beautiful dark UI with animations
- 🔗 Every resource directly linked
- ✨ Easy to update — just edit `data/resources.js`
